Security

Security is a first-class concern. Here is our posture, in plain terms.

The VAKED contract

  • Open source — the full source is published in the pocoo.vaked.dev repository.
  • Source-verified — the deployed bytecode is verified as an exact (full) match on Sourcify.
  • Regression-tested — the mint, difficulty-adjustment, and supply logic is covered by Foundry and Hardhat test suites.
  • Immutable after renounce — once ownership is renounced to the zero address, there is no admin key, no pause, no upgrade path. That is the point, and it is also a responsibility: the code must be right before that final step.

Responsible disclosure

If you find a vulnerability — in the contract, the site, or any surface — please email peter.lodri@gmail.com. Do not exploit it publicly; give us a reasonable window to respond and fix before disclosure.

There is no formal bug bounty at this time, but genuine, responsibly-reported findings are appreciated and credited.
